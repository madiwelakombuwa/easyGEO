API Endpoints

1. GET / - API Documentation

Returns API information and available endpoints.

curl https://easygeo.harsha-4cf.workers.dev/

2. GET /health - Health Check

Check if the API is operational.

curl https://easygeo.harsha-4cf.workers.dev/health

3. POST /convert - Convert HTML to Markdown

Convert HTML content to Markdown format.

Request Body:

{ "html": "string (required)", "baseUrl": "string (optional)", "options": { "includeImages": true, "includeLinks": true, "includeTables": true, "includeCodeBlocks": true } }

Example Request:

curl -X POST https://easygeo.harsha-4cf.workers.dev/convert \ -H "Content-Type: application/json" \ -d '{ "html": "<h1>Hello World</h1><p>Test</p>", "baseUrl": "https://example.com" }'

Response:

{ "success": true, "markdown": "# Hello World\n\nTest", "length": 18 }

Supported HTML Elements

  • Headings: h1-h6
  • Text formatting: strong, em, u, del, mark, sup, sub
  • Lists: ul, ol, dl
  • Links and images: a, img
  • Tables: table, tr, td, th
  • Code: pre, code, kbd
  • Blockquotes: blockquote
  • And many more!
